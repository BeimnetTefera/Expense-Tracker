– ETB
read from SQLite, no LLM

How it works

  1. Your message and a list of tool descriptions go to an LLM on Groq.
  2. The LLM can only ask for a tool. Python looks the name up in an allowlist and validates the arguments with Pydantic. Bad arguments go back to the LLM as an error so it can fix them.
  3. The tool runs plain Python against SQLite. The result goes back to the LLM, and the loop repeats (at most 5 rounds) until it writes an answer.
  4. Deleting is split in two: the LLM can propose a delete, but only you can approve it. The approve action isn't a tool, so the LLM has no way to call it.
